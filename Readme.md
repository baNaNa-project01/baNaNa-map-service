# [현재 상황]

### 25/02/14 구현 상황

###### <hr>

- 오늘 밤까지 기능 구현 완료후 app.js 기능별로 ES6 모듈 방식으로 파일 분리 예정. 각 파일은 기능별로 코드가 나뉠 예정이며 HTML파일에서는 마지막에 main.js를 모듈로 불러오도록 함.
- 🔥100커밋 달성🔥
- 이미지가 없는 관광지 게시글에 기본 이미지를 넣는 코드 추가
- 상세 페이지에서 이미지 보이지 않는 오류 해결 및 2가지일시 슬라이드로 볼 수 있음.
- server.js에서 TourAPI: 상세 관광정보 조회 엔드포인트 신규 루트 생성
- 게시판에서 관광정보 목록 클릭하면 상세페이지 팝업이 뜬다.
- 상세 관광정보 팝업 페이지 생성
- 조회된 데이터가 없으면 alert로 "조회된 데이터가 없습니다"라는 알림창 나오게함.
- 현재 게시판에서 관광정보 클릭시 팝업? 창을 만들어 관광지에 대한 보다 자세한 정보를 확인할 수 있는 기능 추가중.. 행사/공연/축제, 숙박의 경우 보다 정확한 정보를 확인 할 수 있게 구현하는게 목표
- 이제 관광정보를 조회하면 지도에 마커뿐만 아니라 아래에 게시판 추가해서 게시판으로도 관광정보를 확인할 수 있다.
- 이전 깃에서 해당 함수 코드만 복붙후 버그 수정완료.
- 새로운 기능 추가하면서 실수로 카테고리 검색 함수와 마커관련 css코드 삭제했었음.
- 근데 갑자기 기존의 카테고리 검색 버튼이 오류남.
- 출력되는 데이터들을 지도의 마커로 표시하고 인포위도우에 해당 장소의 정확한 정보들을 표시
- 지역선택, 세부지역선택, 관광타입선택 버튼 만들고 조회하기 버튼 누르면 해당하는 데이터들 json형식을 출력되는거 확인
- TourAPI 연동 후 데이터 읽어오기 성공
- 상단의 배너와 현재위치 버튼 검색창이 스크롤을 내려도 내려오지 않게 UI 수정
- 관광지 데이터를 보여주기 위한 공간을 위해 지도 영역을 제한하고 카테고리 박스UI를 지도 우측으로 변경

### 25/02/13 구현 상황
