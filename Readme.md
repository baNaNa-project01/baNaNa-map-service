# [현재 상황]

### 25/02/13 구현 상황

###### <hr>

- 기존에는 목록항목에 마우스를 올려놓으면 인포위도우가 열렸는데 항목을 클릭해야 열리게 수정 및 UI 개선
- 장소 검색후 목록으로 보여주는 기능 구현
- 검색시 조회되는 인포위도우 창들을 닫을 수 없는 버그 수정
- 검색시 조회되는 인포위도우 창을 띄어놓은 상태에서 다른 지역 검색시 지워지지 않는 버그 수정
- 검색 데이터들 마커로 지도에 표시 및 상세 정보 인포위도우에 나타남
- 검색시 조회된 장소 주변 장소들을 console.log에서 확인
- 카카오 검색 기능 오류 해결

### 25/02/12 구현 상황

###### <hr>

- 카카오 검색 기능 오류 발생
- 검색기능을 위한 카카오API 연동 성공(네이버는 공식 가이드가 카카오보다 불편하다..)
- 검색창 추가(아직 기능 구현중..)
- 현재 위치 마커 아이콘 주변에 이펙트 퍼져나가는 애니메이션 적용
- 현재 위치 마커 아이콘 커스텀 이미지 적용(테스트용 이미지고 후에 바꿈)
- 현재 위치 불러오기 기능 구현 완료
- 현재위치를 불러오는 기능 구현을 위해 jQuery 적용중
- 장소 데이터를 express를 이용해 server.js에서 docs/app.js로 전송
- 마커 인포윈도우에 테스트용 장소 데이터 삽입 성공
- 마커 여러개 추가
- 테스트용 마커 추가
- 테스트 하기 위해 확정된 UI가 아닌 임의로 배너 및 현재 위치 인포위도우 추가
- 처음 커밋했을 때 키 노출되어 키 재발급
- express 서버에 dotenv 사용하여 네이버apikey 숨김
- 네이버지도API 연동 오류 해결
  - Client Secret이 아니라 Client ID를 넣어야함
  - 서비스 URL 등록할 때 http://localhost 뒤에 포트 번호 적으면 안됌
